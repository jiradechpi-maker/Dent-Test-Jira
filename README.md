## เชื่อม Google Drive (ตารางสอน / ตารางคุมสอบ)

แอปอ่านไฟล์อย่างเดียว ไม่เขียนกลับ — การแก้ตารางยังทำในไฟล์ต้นฉบับเหมือนเดิม ปีอื่นที่เจ้าหน้าที่คนอื่นดูแลจึงไม่ถูกแตะต้อง
ระบบถาม Drive ทุก 30 วินาที (หน้าเว็บถามทุก 2 นาที) ว่าไฟล์ถูกแก้ไหม และดาวน์โหลดใหม่เฉพาะตอนที่ `modifiedTime` เปลี่ยน

1. Google Cloud Console → สร้างโปรเจกต์ → เปิด **Google Drive API**
2. IAM & Admin → Service Accounts → Create → เข้าไปที่ Keys → Add key → JSON (ได้ไฟล์ `.json`)
3. Vercel → Settings → Environment Variables → `GOOGLE_SERVICE_ACCOUNT_JSON` = เนื้อหาไฟล์ JSON ทั้งก้อน → Redeploy
4. เปิดไฟล์บน Drive แต่ละไฟล์ → **แชร์** → ใส่อีเมล `client_email` ของ service account → สิทธิ์ **ผู้มีสิทธิ์อ่าน (Viewer)**
   (ไฟล์ที่เราไม่ได้เป็นเจ้าของ ต้องเป็นผู้แก้ไขจึงจะแชร์ต่อได้ หรือขอให้เจ้าของไฟล์แชร์ให้)

ไฟล์ที่ใช้ตั้งค่าไว้ใน `src/config/data-sources.ts` (เปลี่ยนได้ด้วย `SCHEDULE_YEAR4_FILE_ID`, `INVIGILATION_FILE_ID`)
ถ้ายังไม่ได้ตั้ง service account แต่ไฟล์เปิด “ทุกคนที่มีลิงก์” ระบบจะอ่านผ่านลิงก์สาธารณะแทน และระหว่างนี้อัปโหลดไฟล์ `.xlsx` เองในหน้าเว็บได้

ตรวจตัวอ่านกับไฟล์จริงในเครื่อง: `npx tsx scripts/inspect-sheets.mts --teaching ปี4.xlsx --invigilation คุมสอบ.xlsx`

## วิธีใช้นาฬิกาจับเวลาสอบ

1. **ตั้งค่าการสอบ** ทำตามขั้นตอน ① การสอบ (ชื่อวิชา ห้อง หรือกดรายการ “สอบวันนี้”) ② เวลาเริ่ม–เลิก ③ กติกาเข้า–ออกห้อง แล้วกด **เริ่มจับเวลา**
   (หรือ **เริ่มสอบเดี๋ยวนี้** ถ้าไม่ต้องรอเวลาเริ่ม)
   กติกาเข้า–ออกห้อง ค่าเริ่มต้นตามข้อบังคับสถาบัน ข้อ ๒ (สายได้ไม่เกิน 30 นาที · ออกได้เมื่อสอบไปแล้ว 1 ชั่วโมง) กดเปลี่ยนได้:
   เข้าสาย **ไม่ให้สาย / 15 นาที / 30 นาที** · ออกได้หลัง **30 นาที / 1 ชั่วโมง**
   (สอบสั้นจนไม่มีช่วงที่ออกได้ เช่น สอบ 1 ชม. จอจะขึ้น “ออกจากห้องสอบไม่ได้จนหมดเวลาสอบ”)
2. **④ ข้อปฏิบัติสำหรับนักศึกษา** (ข้อบังคับ ข้อ ๑๐ ให้แจ้งก่อนสอบทุกครั้ง ทั้งทางวาจาและลายลักษณ์อักษร)
   - ก่อนเริ่มสอบ จอแสดงข้อปฏิบัติ 6 ข้อ 2 ภาษา (เวลาเข้า–ออก · บัตรแสดงตน · มือถือ · สิ่งของต้องห้าม · การแต่งกาย · ทุจริต) พร้อมนับถอยหลัง
   - สวิตช์ “วิชานี้อนุญาตให้ใช้เครื่องคิดเลข” ปรับข้อความเรื่องสิ่งของต้องห้ามให้
   - ปุ่ม **พิมพ์ประกาศข้อปฏิบัติ (A4)** — ฉบับเต็มตามข้อบังคับ ข้อ ๒–๙ ใส่ชื่อวิชา ห้อง วันเวลาให้ ติดหน้าห้องหรืออ่านให้นักศึกษาฟัง
3. **⑤ เสียงกริ่งและการเตือน**: กริ่งตอนเริ่มสอบและหมดเวลา · เมื่อเหลือ 5 นาที ดังกริ่งแล้วขึ้นข้อความบนจอ 1 นาที ให้กรรมการคุมสอบอ่านประกาศ
   ข้อความมาตรฐาน: “เหลือเวลาสอบอีก 5 นาที กรุณาตรวจสอบความถูกต้อง และอย่าลืมเขียนชื่อและเลขที่ ID” (กด “แก้ข้อความ” เพื่อเปลี่ยน)
   (เสียงพูดอัตโนมัติถอดออกไว้ก่อน — ยังอยู่ในประวัติ git ถ้าจะกลับมาทำต่อ)
4. กด **แสดงเต็มจอ** (หรือปุ่ม `F`) — `M` ปิด/เปิดเสียงทั้งหมด

ระบบเทียบเวลากับเซิร์ฟเวอร์ให้อัตโนมัติ ถ้านาฬิกาเครื่องในห้องสอบเพี้ยน ระบบจะแก้ให้ และถ้าเผลอรีเฟรชหน้า การจับเวลาก็ยังเดินต่อ

## ดูเว็บหลังแก้ไข (ทำทุกครั้งที่มีงานใหม่เสร็จ)

งานใหม่จะถูกส่งขึ้น GitHub ใน branch แยกก่อนเสมอ ต้องรวมเข้า `main` เว็บจริงบน Vercel จึงจะอัปเดต

1. เข้า GitHub ของโปรเจกต์ → ถ้ามีแถบเหลือง “had recent pushes” กด **Compare & pull request** → กด **Create pull request**
   (ไม่มีแถบ: แท็บ **Pull requests** → **New pull request** → base `main` · compare branch งาน → **Create pull request**)
2. (ถ้าอยากลองก่อน) รอให้ในหน้า PR ขึ้น ✓ ของ Vercel แล้วกดลิงก์ **Preview** — เป็นเว็บทดลอง ไม่กระทบเว็บจริง
3. กด **Merge pull request** → **Confirm merge**
4. รอ 2–3 นาที → vercel.com → โปรเจกต์ → **Deployments** แถวบนสุดขึ้น **Ready** = เว็บจริงอัปเดตแล้ว
5. เปิดเว็บจริง กด **Ctrl+Shift+R** (Mac: **Cmd+Shift+R**) เพื่อโหลดหน้าใหม่ แล้วลองใช้เมนูที่แก้

ถ้า Deployments ขึ้น **Error** สีแดง ให้ถ่ายรูปส่งให้ผู้พัฒนา เว็บจริงจะยังเป็นรุ่นก่อนหน้า ไม่พัง

### PDF และการพิมพ์

ไม่ต้องตั้งค่าอะไร: หนังสือเชิญถูกจัดหน้าเป็น HTML ขนาด A4 ตามไม้บรรทัดเดียวกับไฟล์ Word (`src/components/documents/letter/`)
ใช้ฟอนต์ TH Sarabun New ตัวจริง (`public/fonts/`) ทั้งพรีวิว · ปุ่ม “พิมพ์ / บันทึกเป็น PDF” (Ctrl+P) · และปุ่ม “ดาวน์โหลด PDF” (สร้างไฟล์ในเบราว์เซอร์)

**ตัดคำไทย:** เบราว์เซอร์และ LibreOffice ตัดคำไทยด้วยพจนานุกรม ICU ซึ่งหั่นคำประสม (เช่น `ทันตแพทย|ศาสตรบัณฑิต`)
`src/lib/thai-wrap.ts` จึงกำหนดคำที่ห้ามตัด (คำในหนังสือราชการ + ชื่อคนทุกคำ) — ใน HTML ใช้ `white-space: nowrap`
ส่วนไฟล์ที่ส่งให้ LibreOffice แปลง PDF จะถูกตัดคำล่วงหน้าทั้งย่อหน้า (word joiner ภายในคำ / zero-width space ระหว่างคำ)
ไฟล์ `.docx` ที่ผู้ใช้ดาวน์โหลดไม่ถูกแก้ — MS Word ตัดคำไทยด้วยพจนานุกรมของตัวเอง

**Gotenberg (ไม่บังคับ):** ถ้าตั้ง `GOTENBERG_URL` (ฝั่งเซิร์ฟเวอร์) และเชื่อมต่อได้ ระบบจะใช้ PDF ที่แปลงจากไฟล์ Word โดย LibreOffice แทน
(ตรวจผ่าน `/api/health` อัตโนมัติ — ถ้าเชื่อมไม่ได้จะกลับไปใช้แบบในเบราว์เซอร์เอง ไม่ขึ้น error)

```bash
docker compose up -d gotenberg   # build จาก docker/gotenberg (มีฟอนต์ TH Sarabun New)
# .env.local → GOTENBERG_URL="http://localhost:3001"
```

ถ้าไม่มี Docker แต่มี LibreOffice และฟอนต์ TH Sarabun ในเครื่อง ใช้ตัวแทนแบบง่ายได้: `node scripts/local-pdf-server.mjs`

### Deploy บน Vercel

1. Import repo นี้บน Vercel (Framework: Next.js ไม่ต้องตั้งค่าอื่น)
2. Deploy Gotenberg แยกต่างหาก เช่น Google Cloud Run จาก `docker/gotenberg/Dockerfile` (port 3000)
3. ตั้ง Environment Variable `GOTENBERG_URL` บน Vercel ให้ชี้ไปที่ URL ของ Gotenberg
   (ถ้าเปิด basic auth ให้ใส่ `GOTENBERG_USERNAME` / `GOTENBERG_PASSWORD` ด้วย)
